# Hollow Knight 触觉事件映射审计说明

## 审计方法

游戏内全部 PS5 精细触觉震动事件 = `GamepadVibration` ScriptableObject 资产。通过只读扫描
`E:\steam\...\hollow_knight_Data\*.assets`（绕开 `.resS` 流式数据，直接解析 MonoBehaviour 头部
的 `m_GameObject`/`m_Script`/`m_Name` 字段），按 `m_Script=(1,228)` 指针精确定位到
**共 23 个真实震动事件名**。这是游戏运行时可能触发的全集，无需人工逐事件覆盖。

## 静态核对结果（23 个事件 vs clips 目录 314 个 WAV）

匹配算法（`HapticMixerWrapper.ResolveClipFile`）：显式别名 > 归一化精确 > 最长子串模糊。

### ⚠️ 保留 rumble 回退（2/23，非映射缺失）

| 游戏事件名 | 原因 |
|---|---|
| Fireball（复仇之魂/暗影之魂法术） | clips 目录中**无任何对应 WAV 触觉素材**；原版 PS5 即使用 rumble |
| Scream（尖叫） | clips 目录中**无任何对应 WAV 触觉素材**；原版 PS5 即使用 rumble |

搜索验证：在 clips 全部 314 个 WAV 中，以关键词 `fire`/`scream`/`spell`/`howl` 均未找到
（仅命中 `hero_quake_spell_*`，属于地震术而非法术 fireball）。因此**无法为其补别名**——
这是素材层面的客观限制，不是映射遗漏。

```csharp
{ "quakeimpact",       "hero_quake_spell_impact_vibration" },
{ "quakestart",        "hero_quake_spell_prepare_vibration" },
```

其中 `dash` 别名是**误配修复**：原版归一化匹配把 `Dash`（骑士普通冲刺）错配到
`hornet_beast_dash_attack_foley_vibration`（黄蜂兽攻击素材，手感完全不同）。现修正为
`hero_dash_vibration`。

## 关于 "MISS 日志"

本次改动后，若再触发未匹配事件，会在 `BepInEx\LogOutput.log` 里看到 `Haptic MISS: 'xxx'`
告警（每个事件名只报一次）。现在已确认游戏内震动全集 = 23 个，全部覆盖（21 精细 + 2 客观无素材），
所以日志里**理论上不会再有新的 MISS 出现**，除非游戏版本更新加入新震动资产。
