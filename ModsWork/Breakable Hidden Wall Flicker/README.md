# 隐藏墙壁可视化

**版本：** 1.2.1  
**作者：** 原作者未知

## 功能描述
让可破坏的墙壁/地板闪烁，使其更容易被发现。

### 功能特性：
- **启用闪烁**：让可破坏墙壁/地板闪烁，使其更容易被发现。关闭仅改变颜色。
- **加速闪烁**：让闪烁动画速度更快。
- **禁用墙面遮罩**：移除隐藏机密区域的黑色遮罩。
- **启用墙面粒子**：为可破坏墙壁/地板添加发光粒子效果。
- **粒子流向玩家**：玩家靠近时，粒子会被吸引向玩家方向移动。

## 适配说明
本模组已适配空洞骑士应用程序接口（Modding API），取代了原有的 HKMP/BepInEx 加载器依赖。
