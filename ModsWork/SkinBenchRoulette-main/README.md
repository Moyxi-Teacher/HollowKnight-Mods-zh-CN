# SkinBenchRoulette 🎡🪑

A Hollow Knight mod that randomizes your **Custom Knight** skin every single time you sit on a bench! 

## Features 🌟
* **Fully Automated**: Automatically scans your `Custom Knight/Skins` directory. You don't need to hardcode your skin names anymore!
* **Delay protection**: Waits for the Knight to fully sit down before triggers, preventing animation glitches.
* **Open Source**: Lightweight implementation using Reflection to stay independent from specific assembly updates.

---

## Recursos (Português) 🇧🇷
* **Totalmente Automático**: O mod varre sozinho a sua pasta de skins do Custom Knight. Você nunca mais precisa atualizar o código para adicionar skins novas!
* **Leve e Seguro**: Desenvolvido usando Reflection para garantir compatibilidade com futuras atualizações do jogo.
