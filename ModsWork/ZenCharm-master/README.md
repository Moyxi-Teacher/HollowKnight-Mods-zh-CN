# ZenCharm

A Charm mod for hollowknight that adds the ZenCharm.

A new charm that allows the user to be calm and focused without a bench. while equiped you can change other charms without a bench.

You will not be able to unequip this charm while not at a bench.

you can equip Jonis Charm however it will have no effect until you sit at a bench

if you equip the fragile / unbreakable health charm, it will update your max health but will not change your current health.

The name is based on the lore that it takes focus and concentration to change charms thus requiring sitting on bench.
The charm aids the player in being able to focus and concentrate on the move for the cost of three charm notches

This charm is based off a request from the discord https://discord.com/channels/879125729936298015/1351567175550373928

### Dependencies

requires hkModding Api and SFCore to be installed
