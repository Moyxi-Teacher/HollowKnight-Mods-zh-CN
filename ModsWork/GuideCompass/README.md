# 攻略指南针（原型）

为《空洞骑士》添加当前攻略目标和指南针。第一期“十字路口的小骑士”按攻略中的任务目标推进；纯移动和战斗技巧合并进相邻目标的提示，不再作为独立目标。黄色空心右指箭头显示在骑士正上方，尖端实时指向目标；在当前场景中找到匹配目标时实时追踪，否则显示路线提示方向。

右上角 UI 参考攻略截图，采用“当前任务 / 现阶段建议”两段式布局，标题前有细横线、任务文字使用绿色、建议文字使用浅色；不绘制黑色底板并根据内容自动换行。字号和位置会随分辨率缩放。界面只在重绘阶段绘制，不处理游戏输入事件。

路线目标仅包括抵达区域、获得物品、隐藏钱袋、打破隐藏墙、交互印记、购买、救幼虫、击败指定敌人、开启车站、使用长椅和 NPC 事件。可观测的目标会自动推进：

- `AtLocation`：抵达指定场景与坐标范围。
- `NearTarget`：靠近当前场景中的指定 NPC；虫爷爷目标只要求到达其位置，不要求对话。
- `WhenPlayerDataBoolIsTrue`：获得物品、购买、解救或击败目标后，对应游戏存档标志变为 `true`。
- `WhenPlayerDataIntReaches`：收集数量等存档整数达到目标值。
- `WhenEnemiesAreDefeated`：击败匹配当前目标对象的指定数量敌人。
- `WhenBenchIsUsed`：使用长椅并设置重生点后推进。
- `WhenFsmStateIsEntered`：NPC 对话或交互进入指定 PlayMaker FSM 状态。
- 钱袋只在指南针当前追踪的 `Geo Rock` 进入 `Destroy` 状态时推进，不受普通吉欧掉落拾取影响；打破墙的目标也必须匹配当前追踪对象。可直接进入的暗门不单独检测破坏，直接以其中的钱袋作为目标。蓝血容器破坏通过游戏对象事件推进；白王印记通过其交互 FSM / 事件推进。

可选精英战由 `F7` 跳过；`F6` 返回，`F7` 前进，`F8` 隐藏/显示。攻略目标为四只幼虫，但正文只给出前三只的具体路线；第四只由幼虫计数自动判定，并提示根据地图寻找。可选出生地路线在取得亡者之怒或抵达德特茅斯后自动略过。

当前目标、可选击杀计数和路线完成状态随游戏存档的模组本地设置保存；读档后会从保存位置继续，并自动略过已能从游戏存档状态判断完成的目标。路线定义变更时会通过进度版本号安全重置旧索引，再依据当前存档标志跳过已完成目标。从模组菜单中的“重置攻略进度”按钮回到第一步。攻略步骤名和提示为简要自述整理，未复制原文。

## 构建

```powershell
dotnet build .\GuideCompass.csproj -c Release "-p:HollowKnightRefs=E:\steam\steamapps\common\Hollow Knight\hollow_knight_Data\Managed"
```

编译产物位于 `bin\Release\GuideCompass.dll`。测试时将 DLL 放进游戏的 `Managed\Mods\攻略指南针\` 文件夹。
