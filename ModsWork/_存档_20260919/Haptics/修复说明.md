## 一、现象

装备震动模组（Hollow Knight Haptics 0.1.2）后，小骑士释放 **荒芜俯冲** / **黑暗降临**：

| 阶段 | 游戏事件名 | 修复前表现 |
|---|---|---|
| 第一段：空中蓄力 | `hero_quake_spell_prepare` | ✅ 有震动 |
| 第一段：下砸飞行 | `hero_quake_spell_dash` | ✅ 有震动 |
| 第二段：砸地冲击 | `hero_void_quake_impact` | ❌ 无震动 |

## 二、日志证据（Player.log）

一次完整下砸对应 4 行日志：

```
[Info   :Hollow Knight Haptics] Haptic input: 'hero_quake_spell_prepare' (...)   →  Haptic play ✅
[Info   :Hollow Knight Haptics] Haptic input: 'hero_quake_spell_dash' (...)      →  Haptic play ✅
[Info   :Hollow Knight Haptics] Haptic input: 'hero_void_quake_impact' (...)
[Warning:Hollow Knight Haptics] No haptic wav (yet) for clip 'hero_void_quake_impact' - rumble fallback
[Warning:Hollow Knight Haptics] Haptic MISS: 'hero_void_quake_impact' (tag='heroAction') — 无匹配 WAV，回退 rumble
[Info   :Hollow Knight Haptics] Haptic input: 'shake_loop' (...)                 →  Haptic play ✅
```

全日志统计：

| 事件名 | input 次数 | play 次数 |
|---|---|---|
| `hero_quake_spell_prepare` | 15 | 14 ✅ |
| `hero_quake_spell_dash` | 14 | 14 ✅ |
| `hero_void_quake_impact` | 14 | **0** ❌ |
| `hero_land_soft` | 19 | 19 ✅ |
| `shake_loop` | 14 | 14 ✅ |

`hero_void_quake_impact` 是唯一「触发了却从未成功播放」的事件。

## 三、根因

模组把游戏事件名解析成 clips 目录里的触觉 WAV（`HapticMixerWrapper.ResolveClipFile`），
匹配顺序为：显式别名 → 自动别名 → 归一化精确匹配 → **包含匹配**。归一化规则 = 转小写 + 去下划线。

- 游戏事件名：`hero_void_quake_impact` → 归一化 `herovoidquakeimpact`
- 目标素材名：`hero_quake_spell_impact_vibration` → 归一化 `heroquakespellimpactvibration`

两者**互不包含**（`void` 与 `spell` 词元不同、`void` 段缺失），四条匹配路径全部落空
→ `TryGetPcm` 返回 false → 判定 MISS → 回退普通双马达 rumble（玩家侧感知为「砸地没震动」）。

前两段之所以正常，是因为 `hero_quake_spell_prepare` / `hero_quake_spell_dash`
与同名 WAV 存在包含关系，能自动命中。

## 四、修复内容

在 `HapticMixerWrapper.cs` 的 `clipAliases` 显式别名表中新增一条（与既有 `shadowdash` 桥接同一模式）：

```csharp
{ "herovoidquakeimpact", "hero_quake_spell_impact_vibration" },
```

修复后调用链：

```
hero_void_quake_impact
  → clipAliases 命中
  → hero_quake_spell_impact_vibration
  → TryGetPcm 加载 clips\hero_quake_spell_impact_vibration.wav
  → PS5HapticEmission 注册 → Bridge 精细触觉播放 ✅
```

目标素材已验证可直接被加载器接受：

- RIFF / WAVE 标识正确
- 格式 = 1（PCM，代码要求 `fmt == 1`，否则抛异常）
- 立体声 / 48000 Hz / 16 bit（与 `HapticEngine` 的期望完全一致）
- 时长 1.90 秒

## 七、验证方法

1. 启动游戏释放一次荒芜俯冲或黑暗降临。
2. 查看 `Player.log`，落地段应出现：

```
[Info   :Hollow Knight Haptics] Haptic input: 'hero_void_quake_impact' (bridge=True, looping=False, tag='heroAction')
[Info   :Hollow Knight Haptics] Haptic play: 'hero_void_quake_impact' (loop=False, tag='heroAction')
```

   （不再出现 `Haptic MISS: 'hero_void_quake_impact'`）
3. 手感确认：砸地瞬间应有明显震动，且与蓄力段同属精细触觉通道。

## 八、可调项

- 砸地震感强弱：游戏内模组菜单 → Haptics 分类 → **「地震术落地」** 倍率（默认 1.0，范围 0~3）。
- 素材时长 1.90 秒，若尾震偏长需要更换素材，请另行提出。
