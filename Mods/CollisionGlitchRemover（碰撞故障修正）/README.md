# CollisionGlitchRemover（碰撞故障修正）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | HK.CollisionGlitchRemover |
| 中文名称 | 碰撞故障修正 |
| 模组类型 | 功能模组 |
| 模组版本 | 1.0.2汉化 |
| 模组作者 | 原作者未知 |

## 模组简介

修复碰撞类故障，如格鲁兹母墙弹跳和收藏家「黏脚」等问题。需要 SFCore。

## 安装方法

将本目录中的 `CollisionGlitchRemover.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。
