# BenchWarpFix（长椅传送修正）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | BenchWarpFix |
| 中文名称 | 长椅传送修正 |
| 模组类型 | 功能模组 |
| 模组版本 | 1.5.1.3汉化 |
| 模组作者 | SFGrenade |

## 模组简介

当英雄掉出地图边界时，自动传送回德璞镇以防止卡在外层空间。

## 安装方法

将本目录中的 `BenchWarpFix.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。
