# SFCore（核心）——汉化版

**模组原名**：SFCore  
**版本**：1.5.14.8汉化  
**适用游戏**：Hollow Knight（空洞骑士）

SFCore 是面向需要向游戏中添加自定义成就、物品与护符的模组所提供的 Modding API 辅助库。

## 汉化说明

- **目标**：汉化模组在游戏内玩家可见的文本，仅限文本/字符串层面。
- **内容**：修订 `Resources/Language.json` 中 `ZH`（中文）文本。英文 `"ITEMS_COLLECTED": "Collected"` 修订为 `"已收集"`。
- **不改动项目**：本次汉化不删除或修改任何源代码引用，未改变 mod 功能逻辑。
- **与原版一致性**：
  - `AssemblyVersion` / `FileVersion` 保留为 `1.5.14.8`（与原版一致）。
  - `InformationalVersion` 为 `1.5.14.8汉化`（菜单悬停显示）。
  - 强名称签名与原版保持一致（均为 `PublicKeyToken=null`，未签名）。
