# 圣巢之声（Hallownest-Vocalized）——汉化版

- **模组原名**：Hallownest-Vocalized
- **版本**：0.0.1.4汉化
- **适用游戏**：Hollow Knight（空洞骑士）

## 汉化说明

- **目标**：汉化模组在游戏内玩家可见的文本，仅限文本/字符串层面。
- **内容**：修订模组显示名、菜单文本及内嵌语言资源中的中文文本。
- **不改动项目**：本次汉化不删除或修改任何源代码引用，未改变 mod 功能逻辑。
- **与原版一致性**：
  - `AssemblyVersion` / `FileVersion` 保留原版数字版本。
  - `InformationalVersion` 为 `0.0.1.4汉化`（菜单悬停显示）。
  - 强名称签名与原版保持一致（均为 `PublicKeyToken=null`，未签名）。
- **语言回退**：非中文语言严格返回原英文，仅中文语言显示中文。

## 功能

为 Hollow Knight 添加 Hallownest 风格的角色语音配音，覆盖以下场景：

- 商店 NPC 对话
- 物品栏对话
- 梦钉对话
- 自动 Boss 呐喊
- 菜单 UI 语音
- 环境音频衰减

## 游戏内菜单

本模组支持通过游戏内模组列表开启/关闭。点击「圣巢之声」条目后进入完整自定义菜单（圣巢之声），其中可调整：

- 圣巢之声音量
- 自动滚动
- 滚动锁定
- 梦钉对话
- 自动 Boss 呐喊
- 衰减音频
- 商店/物品栏音频

## 安装

1. 将本文件夹内的 `HKVocal.dll` 复制到游戏的 `hollow_knight_Data/Managed/Mods/` 目录
2. 同时复制 `HKVocal.pdb`（调试符号，可选）
3. 启动游戏后，在模组菜单中启用「圣巢之声」

## 设置

游戏内可通过音频菜单中的「前往圣巢之声设置」按钮调整：

- 圣巢之声音量
- 自动滚动
- 滚动锁定
- 梦钉对话
- 自动 Boss 呐喊
- 衰减音频

## 注意

- 首次启用时建议检查系统音频设置
