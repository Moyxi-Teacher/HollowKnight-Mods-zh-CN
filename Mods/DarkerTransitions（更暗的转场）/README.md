# DarkerTransitions（更暗的转场）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | DarkerTransitions |
| 中文名称 | 更暗的转场 |
| 模组类型 | 功能模组 |
| 模组版本 | 0.1.0汉化 |
| 模组作者 | RiverRobot |

## 模组简介

将战斗转场中的白光替换为黑色，视野更暗。影响包括诸神堂竞技场入口转场、六统之王转场和梦中 Boss 的进入/离开转场。

## 安装方法

将本目录中的 `DarkerTransitions.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。

- 诸神堂竞技场入口转场

- 梦之 Boss 的进入/离开转场
