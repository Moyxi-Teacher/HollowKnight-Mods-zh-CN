## 简介

地图变更（MapChanger）是一个 Hollow Knight 地图修改 API。

它允许修改游戏中已有的地图行为，包括暂停菜单地图的显示、地图模式切换、以及一组用于快速切换地图相关功能的全局热键。

## 依赖模组

- MagicUI（魔法界面）
- Satchel
- Vasi

## 可选兼容

- AdditionalMaps（额外地图）
- DebugMod（调试Mod）

> 如需使用地图变更提供的全部功能，请确保上述依赖模组已安装且为最新版本。

## 菜单

启用“地图变更”后，进入模组菜单中可见“地图变更”一栏，包含以下选项：

- **显示暂停菜单**：开启/关闭地图模组的暂停菜单界面。

## 热键

- **Ctrl + M**：启用/禁用地图模组。
- **Ctrl + T**：切换地图模式。
