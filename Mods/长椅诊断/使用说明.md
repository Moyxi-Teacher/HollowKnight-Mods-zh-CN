## v11 新增：引用变化的实时监控

上一轮已经证明「引用在场景加载时是好的，按上键时已经变坏」，
但**不知道是在哪一刻被改坏的**。v11 补上这一环：

新增 `⚡ CanInput 目标变化` 行，**每帧**检查所有长椅状态机的 CanInput 目标，
一旦发生变化就立刻记下来（变化前后是谁、第几次场景加载、第几帧、当时玩家状态）：

```
[长椅诊断] ⚡ CanInput 目标变化："kompanion"(实例 -133104) ← 原为 "Knight"(实例 207954)（第 3 次场景加载 / 第 13742 帧）
[长椅诊断]    └ 此刻玩家状态：CanInput()=True onGround=True … | acceptingInput=True
```

场景加载后还会先记一条基线：

```
[长椅诊断] 开始监控 3 个长椅状态机的 CanInput 目标（基线：…）
```

### 其余沿用 v10

| 标记 | 含义 |
|---|---|
| `▸ 状态机 xxx 进入「状态名」` | 关键状态轨迹 + 玩家实时状态 |
| `★ 第 N 次进入「Can Rest?」` | 进入判定状态时的引用解析状态 |
| `◆ 离开「Can Rest?」` | 判定所用变量全量、判定结论、CanInput 目标解析、玩家实时状态 |
| `===== 第 N 次场景加载 =====` | 场景加载后的变量表与原始引用状态 |
