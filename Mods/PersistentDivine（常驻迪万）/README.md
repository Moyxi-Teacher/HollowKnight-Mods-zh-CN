# PersistentDivine（常驻迪万）

## 模组简介

确保你在驱逐骸骨众后不会错过在 Dirtmouth 获取不可破坏护符的机会。

## 安装方法

将本目录中的 `PersistentDivine.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。

## 原始 README

A mod that ensures you don't accidentally miss the chance to get unbreakable charms by keeping Divines tent in Dirtmouth even after you banish the Grimm Troupe.
