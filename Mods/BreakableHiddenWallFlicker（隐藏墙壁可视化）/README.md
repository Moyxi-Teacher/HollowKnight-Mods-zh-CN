## 模组简介

本模组用于让可破坏的隐藏墙壁/地板（如"Break Wall""Breakable Wall""Break Floor""Quake Floor"等）持续闪烁并发光，使其更容易被玩家发现；同时可选移除隐藏机密区域的黑色遮罩、添加墙面粒子效果。

> ⚠️ 本 DLL 为**汉化版**：模组在游戏内模组列表与运行日志中的显示名已翻译为中文「隐藏墙壁可视化」，所有菜单文本均已汉化。模组功能逻辑与原版完全一致，未删除任何源代码引用。

## 安装方法

1. 确认已安装 Hollow Knight API（如 Modding API / Scarab 管理器）。
2. 将本目录下的 `BreakableHiddenWallFlicker.dll` 与 `BreakableHiddenWallFlicker.pdb` 复制到游戏的 `hollow_knight_Data/Managed/Mods/` 目录中（与同名文件夹并列）。
3. 启动游戏，在模组列表/设置菜单中即可看到中文显示名「隐藏墙壁可视化」及其菜单项。
