
# Hollow Knight: Pale Court（苍白宫廷）——汉化版

- **模组原名**：Pale Court
- **版本**：1.1.1.0汉化
- **适用游戏**：Hollow Knight（空洞骑士）

## 汉化说明

- **目标**：汉化模组在游戏内玩家可见的文本，仅限文本/字符串层面。
- **内容**：修订模组显示名、菜单文本及内嵌语言资源中的中文文本；译名依据《空洞骑士》中文维基（hkss.huijiwiki）及官方简体中文汉化体系。
- **译名要点**：五骑士 海格默/德莱娅/伊思玛/泽莫尔/奥格瑞姆；圣巢、容器、骨钉、虚空等均与维基一致。
- **不改动项目**：本次汉化不删除或修改任何源代码引用，未改变 mod 功能逻辑。
- **与原版一致性**：
  - `AssemblyVersion` / `FileVersion` 保留原版数字版本。
  - `InformationalVersion` 为 `1.1.1.0汉化`（菜单悬停显示）。
  - 强名称签名与原版保持一致（均为 `PublicKeyToken=null`，未签名）。
- **语言回退**：非中文语言严格返回原英文，仅中文语言显示中文。
