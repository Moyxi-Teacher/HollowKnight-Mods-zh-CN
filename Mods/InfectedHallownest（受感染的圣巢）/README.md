# InfectedHallownest —— 受感染的圣巢（汉化版）

## 模组简介
击败纯粹容器（Hollow Knight 主线 BOSS）后，感染进入第二阶段，会侵袭整个王国中的敌人，使其变为被感染状态，血量翻倍并周期性闪光。

## 游戏内菜单
- 在游戏主菜单的模组管理（Mod Options）中可启用/禁用本模组，菜单项显示为总开关"启用 受感染的圣巢"。

## 安装方法
1. 前提：已安装 Hollow Knight 模组加载器（如 Scarab 或 Modding API 1.5+）。
2. 将 `InfectedHallownest.dll` 放入游戏目录下的 `hollow_knight_Data\Managed\Mods` 文件夹。
3. 启动游戏，在主菜单"模组选项"中开启即可。

## 原版 README（翻译）

# Infected Hallownest

该模组为可怕的感染增加了一层新的复杂性。

在游戏中，当你获得帝王之翼或击败任意一位守梦者时，遗忘十字路就会被感染所吞噬，用更强大的版本替换了许多敌人。

本着这种精神，我为感染的进程增加了一个额外的阶段。在你击败空洞骑士后，感染会蔓延到遗忘十字路之外，使整个游戏中的各种敌人有机会进入"额外感染"状态。

额外感染的敌人会反复闪烁橙色，并且拥有双倍生命值。
