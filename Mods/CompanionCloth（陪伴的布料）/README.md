## 模组简介

召唤布料伙伴在战斗中协助攻击敌人并提供护盾。需要 Vasi。

## 安装方法

将本目录中的 `CompanionCloth.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。

## 中文翻译

一个让你的同伴布料（Cloth）一路陪伴并助战的《空洞骑士》模组。

兼容《空洞骑士》1.5。**需要 Vasi。**

## 功能
本模组允许你按一个按键来召唤（以及取消召唤）布料。
布料可以像叛徒领主 Boss 战那样与你并肩作战。
还允许你按另一个按键将布料传送回你身边。

## 配置
- `SummonKey`（字符串）：召唤/取消召唤布料的按键。默认为 `y`。
- `RecallKey`（字符串）：召回布料的按键。默认为 `u`。

## 贡献
1. 克隆存储库
2. 将环境变量 `HKRefs` 设置为游戏文件中的 `Managed` 文件夹

## 原始 README

# [Companion Cloth](https://github.com/Clazex/HollowKnight.CompanionCloth)
A Hollow Knight mod to let Cloth accompany and fight with you all the way

Compatible with `Hollow Knight` 1.5.
**`Vasi` is required.**

## Features
This mod allows you to press a key to summon (and unsummon) Cloth.
Cloth can fight with you like in Traitor Lord boss fight.
Also allows you to press another key to teleport Cloth back to you.

## Configuration
- `SummonKey` (`String`): The key to summon/unsummon Cloth. Defaults to `y`.
- `RecallKey` (`String`): The key to recall Cloth. Defaults to `u`.
