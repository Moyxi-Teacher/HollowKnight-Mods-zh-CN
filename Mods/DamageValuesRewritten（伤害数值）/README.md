# DamageValuesRewritten（伤害数值）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | DamageValuesRewritten |
| 中文名称 | 伤害数值 |
| 模组类型 | 功能模组 |
| 模组版本 | 1.25.10.07汉化 |
| 模组作者 | jngo102（更新者） |

## 模组简介

当敌人受到直接攻击或 tick 伤害时显示伤害数值。

## 安装方法

将本目录中的 `DamageValuesRewritten.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。
