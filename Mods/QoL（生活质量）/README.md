## 原版 README（翻译）

# HollowKnight.QoL

这是一个空洞骑士模组，包含一些生活质量改进、一些速度跑相关补丁，以及少数原版 Bug 修复。

### 改动列表
- 将背包丢弃、存储、杠杆跳过等 glitch 重新添加。
- 对话即时显示。
- 即时菜单响应。
- 可以切换 Dashmaster（急速大师）向下冲优先级。
- 几乎可以跳过所有过场动画。
- 单次存档可以在 Pain（苦痛）路径中多次游玩。
- 靠近墙壁时不销毁火球。
- 允许在控制设置中绑定更多鼠标按键。
- 修复一些音量缩放问题。
- 与莱姆（Lemm）对话从右侧出售全部物品。
- 包含一个模块，可降低教师档案（Teacher's Archive）乌穆_rng（随机性）。
- 存档现在会生成 .json 备份，可以编辑以便修改存档。
- 神圣之家（Godhome）菜单不再因将攻击绑定到鼠标左键而损坏。

### 默认关闭的改动
- （默认关闭）可以将鼠标光标锁定在游戏窗口。
- （默认关闭）可以禁用硬存档。
