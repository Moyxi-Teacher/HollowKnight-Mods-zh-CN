## 简介

维修虫选项（MenderbugOptions）允许玩家自定义维修虫（Menderbug）的生成行为。

### 功能
- **维修虫无视死亡**：玩家死亡后维修虫依然会生成。
- **维修虫无视告示牌**：告示牌修复后维修虫依然会生成。
- **生成概率（默认：2%）**：调整维修虫生成概率的滑块，范围 0–100%。
- **50% 生成概率**：一键将生成概率设为 50%。
- **恢复默认值**：将所有设置恢复为默认值。
