## 模组简介

本模组为《空洞骑士》的修复类模组，通过 Harmony 补丁修正多个游戏逻辑问题，包括：

- 快速场景加载优化；
- 双跳修正；
- 圣堂零护符修正；
- 神堂相机震动修正；
- 穿越乌姆场景后清理残留水母；
- 神饲巨兽滚动碰撞体修正；
- 灰色王子钉砸碰撞体修正；
- 神堂 HUD 显示检查；
- 场景转场死亡修正；
- 古代盆地喷泉吉欧捐赠修正。

本 DLL 为汉化版：游戏内模组列表/日志中的模组显示名已设置为“非官方补丁修正”。

## 安装方法

1. 将 `UnofficialPatch.dll` 与 `UnofficialPatch.pdb` 放入游戏 `hollow_knight_Data\Managed\Mods\UnofficialPatch\` 目录。
2. 确保游戏环境已安装 BepInEx 5.4.22 或兼容版本。
3. 启动游戏，模组应显示为“非官方补丁修正”。
