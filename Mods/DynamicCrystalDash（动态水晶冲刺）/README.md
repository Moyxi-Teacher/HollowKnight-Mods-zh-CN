# DynamicCrystalDash（动态水晶冲刺）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | DynamicCrystalDash |
| 中文名称 | 动态水晶冲刺 |
| 模组类型 | 功能模组 |

## 模组简介

水晶冲刺速度根据蓄力时间动态变化，替代固定的满速冲刺。

## 安装方法

将本目录中的 `DynamicCrystalDash.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。
