# 模组菜单变更

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | MenuChanger |
| 中文名称 | 模组菜单变更 |
| 模组类型 | 依赖库 |
| 模组版本 | 1.1.0.0汉化 |
| 模组作者 | SFGrenade |

## 模组简介

用于自定义游戏菜单界面的库。提供菜单构建框架，为其他模组添加游戏内菜单扩展。

## 安装方法

将本目录中的 `MenuChanger.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。
本模组已添加到游戏内模组选项菜单，提供模组开关及框架功能描述。
