## 模组简介

本模组会在打破木桶或推车时，按概率掉落吉欧。默认设置下，打破木桶（Barrel）或深渊虫人套装（Deep Egg Set）中的物件有 50% 的概率掉落 1 个吉欧，而推车（Cart）有 75% 的概率掉落 5 个吉欧。

## 安装方法

将本目录中的 `GeoPots.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文「吉欧存钱罐」。汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。

## 中文翻译

本模组会在打破木桶或推车时，按概率掉落吉欧。默认设置下，普通木桶和深渊虫人套装的推车有 50% 的掉落 1 个吉欧的概率，推车则有 75% 的掉落 5 个吉欧的概率。

## 原始 README

# GeoPots
This mod adds geo drops to breakable pots and carts, allowing players to earn more geo from the environment.

By default, small Geo will drop from small pots and the Deep Egg set carts, with a 50% chance for 1 geo, and a 75% chance for 5 geo from carts.

The mod hooks into the Breakable Break event to modify geo drop chances.
