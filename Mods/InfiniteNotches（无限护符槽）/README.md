## 原版 README（翻译）

### Infinite Notches

一个简单的空洞骑士模组，移除护符槽数量限制。

原版游戏中护符槽数量有限制（默认 40 个），使用此模组后限制变为 2000 个，让你可以自由搭配更多护符。模组可通过菜单开关控制是否生效。

### 功能说明
- **无限护符槽**：读取 `PlayerData.charmSlots` 时始终返回 2000，不受实际槽位上限限制。
- **可开关**：通过模组菜单启用/关闭，关闭后游戏恢复正常护符槽数量读取逻辑。

### 安装
将 DLL 放入模组的加载目录即可。使用 HK Mod API 加载，无需 BepInEx。
