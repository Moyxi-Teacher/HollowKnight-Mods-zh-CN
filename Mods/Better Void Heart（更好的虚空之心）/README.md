# Better Void Heart（更好的虚空之心）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | Better Void Heart |
| 中文名称 | 更好的虚空之心 |
| 模组类型 | 功能模组 |

## 模组简介

修改虚空之心与国王之魂的灵魂回复量，可自定义数值。

## 安装方法

将本目录中的 `Better Void Heart.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。

## 原版 README（翻译）

# Better Void Heart

当你拾取虚空之心时，你不会失去国王之魂的灵魂回复量。

你可以在模组菜单中设置灵魂回复量。默认值（国王之魂的值）为 4 点灵魂；你可以将其改为 1、2、4、7 或 11 点灵魂。

需要 Satchel。

## 原始说明的翻译

更好的虚空之心护符逻辑，修复虚空之心在特定情况下的问题。
