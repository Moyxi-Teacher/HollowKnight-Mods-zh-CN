## 原版 README（翻译）

# BenchwarpSpoilerCloak

该模组防止长椅传送功能意外剧透隐藏区域。当你尝试传送到未解锁的长椅时，模组会阻止传送，除非你已穿戴螳螂爪等相应能力。

这可以避免新手玩家在探索过程中意外跳过必要的内容。
