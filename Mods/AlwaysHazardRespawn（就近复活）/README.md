## 原版 README（翻译）

Always Hazard Respawn 是一个空洞骑士模组，在死亡后始终在危险复活点复活。

危险复活点是由于"危险"（如尖刺）导致死亡后你复活的位置。该模组通过利用这些危险生成位置，使你尽可能复活在死亡地点附近。

### 安装
此模组同时支持 HK Modding API 和 BepInEx5。同一 DLL 文件适用于两者。

### 注意事项
**注意：** 死亡时，可能会复活在阴影（Shade）前方。你可能需要返回阴影所在位置。这在 Boss 战斗中尤为常见。请注意，在匆忙进入 Boss 战前，可能会被困在 Boss 房间中，无法取回丢失的吉欧。

**免责声明：** 此模组尚未在整个游戏区域进行充分测试。该模组在死亡时会临时覆盖游戏的复活信息。复活信息会作为存档文件的一部分保存。因此，该模组有可能导致存档损坏。已采取多项措施确保不会发生这种情况。如果确实发生损坏，可能可以通过 Benchwarp 等模组修复。为尽量降低损坏可能性，该模组持续监控游戏何时写入新复活信息并进行跟踪。每次游戏存档时，都会恢复游戏的原始复活信息。此外，复活信息仅在死亡和复活过程中被修改，随后会恢复游戏的原始复活信息。
