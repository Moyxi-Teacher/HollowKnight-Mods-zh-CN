# AdditionalMaps（额外地图）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | AdditionalMaps |
| 中文名称 | 额外地图 |
| 模组类型 | 功能模组 |
| 模组版本 | 1.5.3.4汉化 |
| 模组作者 | SFGrenade |

## 模组简介

添加白宫和诸神之域的地图。

## 安装方法

将本目录中的 `AdditionalMaps.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。

## 中文翻译

一个为空洞骑士添加白宫和诸神之域地图的模组。
