## 模组简介

修改"下冲（Dive/Quake）"的 Spell Control 状态机，移除下摇前摇动作的第二个 Action，使你在下冲期间持续保有无敌帧，避免受到伤害。

## 游戏内菜单

启用总开关"启用 保持下冲无敌帧"即可；关闭后恢复原版前摇逻辑。

## 安装方法

将 `KeepDiveIFrames.dll` 放入游戏目录下的 `hollow_knight_Data\Managed\Mods` 文件夹。
