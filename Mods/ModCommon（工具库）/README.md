# ModCommon（工具库）

## 模组信息

| 项目 | 内容 |
|---|---|
| 原始名称 | ModCommon |
| 中文名称 | 工具库 |
| 模组类型 | 依赖库 |
| 模组版本 | 0.0.6.0汉化 |
| 模组作者 | Kerr |

## 模组简介

通用模组开发辅助库（PlayMaker 与游戏对象工具）。仅作为依赖存在，无独立菜单。

## 安装方法

将本目录中的 `ModCommon.dll` 文件复制到以下游戏模组目录：

```
Steam/steamapps/common/Hollow Knight/hollow_knight_Data/Managed/Mods/
```

## 说明

本 DLL 为**汉化版**，模组在游戏内模组列表中的显示名已翻译为中文。
汉化版本号标记为「汉化」后缀，便于识别。如遇兼容性问题，请备份原版 DLL 后替换。
